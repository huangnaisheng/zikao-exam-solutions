## 使用建议

- **考前一周**：按章节顺序过一遍，重点记「哪个词一出现就该想到哪个结论」。
- **做完错题后**：回到对应的那张图，确认自己错的是概念辨析，还是计算。
- **证明题**：欧拉公式那两条保底不等式值得背下来，2024.04 版结构之后的大题里反复出现。
