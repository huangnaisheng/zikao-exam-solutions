## 使用建议

- **冲刺阶段**：每天扫一遍，重点看「触发条件」那几行，练成条件反射。
- **做题卡住时**：先回来找对应的那张图，再回解析看完整推导。
- **不要只背结论**：这些图省的是「识别题型」的时间，公式本身还得靠在解析里练熟。
