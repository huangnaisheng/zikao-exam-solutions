## 文档结构

每份解析按以下结构编排：

- 试卷结构与考点分布
- 分题解析：题目、答案、考点、解析、易错提醒
- 附录 A：核心公式速查
- 附录 B：易错点清单
- 附录 C：复习建议

文档使用 Markdown 与 LaTeX 编写，GitHub 网页端可直接阅读；本地可使用 Typora、Obsidian 或支持 LaTeX 的 Markdown 编辑器打开。

## 质量说明

- 计算题答案经过独立验算，并与官方答案及评分参考核对。
- 题面经过原卷复核，公式、上下标、积分限及符号均进行检查。
- 文档已完成题号连续性、公式定界符、表格结构、UTF-8 编码及分值合计等检查。
- 如发现题面、答案或推导错误，欢迎通过 Issue 提交勘误，并注明课程代码、考试场次及题号。
