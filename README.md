## 🎯 和"真题合集"有什么不一样

网上不缺真题 PDF，缺的是**讲清楚"这题为什么这么考、下次换个样子你还认不认得出来"**。

本项目的每道题都是固定五段式：

| 段落 | 回答什么问题 |
| :--- | :--- |
| **题目** | 题干与选项完整重排为 LaTeX，公式不再糊成一片 |
| **答案** | 以官方答案册为准，并经过独立验算 |
| **考点** | 一句话说清考什么、属于哪一章 |
| **解析** | 逐步推导，每一步都写清"为什么这么走"，不止停在结论 |
| **易错提醒** | 站在考生角度：会怎么错、错在符号还是系数、错完会落到哪个选项上 |

## 🔍 核心发现二：分值分布六套完全相同

| 章节 | 题号 | 分值 | 占比 |
| :--- | :--- | ---: | ---: |
| 多元函数微分学 | 2、7、13、14、15 | 24 | 24% |
| 无穷级数 | 4、9、19、21 | 17 | 17% |
| 空间解析几何 | 6、11、12 | 15 | 15% |
| 重积分 | 5、8、16 | 12 | 12% |
| 常微分方程 | 3、10、20 | 12 | 12% |
| 曲线积分 | 17、18 | 12 | 12% |
| 曲面积分 | 22 | 5 | 5% |
| 向量代数 | 1 | 3 | 3% |
| **合计** | 22 题 | **100** | 100% |

**这对备考意味着什么**：复习的性价比是可以算出来的。多元微分 24 分、无穷级数 17 分、空间解析几何 15 分——这三块拿走 56 分；而曲面积分只有 5 分、只在第 22 题出现。冲刺阶段的时间该往哪放，一目了然。

## 🔍 核心发现三：章一致 ≠ 考点一致

槽位固定的是**章节**，不是**具体考点**。同一个槽位在不同场次会换花样，例如：

- **第 13 题**（多元微分，6 分）：曲面切平面 ／ 隐函数求偏导 ／ 空间曲线法平面 轮换
- **第 19 题**（无穷级数，6 分）：比值审敛法 ／ 傅里叶系数 ／ 函数展开成幂级数 轮换
- **第 9 题**（无穷级数，3 分）：几何级数求和 ／ 裂项相消 ／ 傅里叶系数 轮换

所以正确姿势不是背答案，而是**按槽位攒变式清单**。每个科目的 `README.md` 里都有一张完整的「槽位 × 变式」对照表，就是这个用途。

## 🚀 怎么用

1. **先看科目 README 的槽位变式表**，建立"第几题考什么"的地图。
2. **按场次刷题**，每份解析的附录 C 都有本卷的复习建议。
3. **错题回到"易错提醒"**——那里写的错法通常就是命题人设计干扰项的思路。
4. **公式渲染**：文档用 LaTeX 书写。GitHub 网页端可直接渲染；本地推荐 Typora、VS Code + Markdown Preview Enhanced、Obsidian。
